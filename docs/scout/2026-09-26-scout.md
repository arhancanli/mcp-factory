# MCP niche scout, 2026-09-26

Scope: where to build MCP servers that can be the best in their niche. Finance, quant and trading are excluded. Every number below was retrieved on 2026-09-26 unless another date is shown, and carries its source. Where something was not measured, it says so.

## 1. The finding that shapes everything

Single-API wrapper servers are now a commodity. One maintainer, `cyanheads`, publishes about 150 repositories, most of them one-source public-data MCP servers (PubMed, openFDA, eCFR, NWS, OSM, CPSC, NHTSA, medical codes, Census, EUR-Lex and many more), almost all pushed in September 2026 (`gh repo list cyanheads --limit 200`, 155 rows, https://github.com/cyanheads). Bulk publishers `pipeworx-io`, `mrfentmen`, `a2awire` and `CSOAI-ORG` fill the official registry with the same kind of wrapper (for example, a search for "recall" returns 35+ entries and "weather" returns 40+, https://registry.modelcontextprotocol.io/v0/servers?search=recall and ?search=weather).

Two consequences:

1. A new wrapper around one free API will not stand out. The wins are in (a) combining several sources into one answer that no single API gives, (b) correctness you can prove with a published golden set, and (c) data that needs real engineering (bulk dumps, offline indexes, parsing), not a thin HTTP pass-through.
2. Small npm download counts are weak evidence. Fresh cyanheads packages with 1 to 3 GitHub stars still show 100 to 500 downloads a week (for example `@cyanheads/grantsgov-mcp-server` 103, `@cyanheads/usaspending-mcp-server` 250, https://api.npmjs.org/downloads/point/last-week/<pkg>, window 2026-09-18 to 2026-09-24). Treat anything in that band as a floor made of mirrors and bots, not proof of users.

## 3. Top 5 in depth

### 3.1 Package truth (score 18, effort M)

What it is: one server a coding agent calls before it writes a dependency. For a package name, or a whole manifest (package.json, requirements.txt, pyproject, Cargo.toml, go.mod, pom.xml), it answers: does it exist, what is the latest stable version, is it deprecated or yanked, which known vulnerabilities affect the pinned version, what licence, how healthy is maintenance, and what the usual replacement is.

Demand evidence:
- The USENIX Security 2025 package-hallucination study found 19.7% of LLM-recommended packages did not exist, across 576,000 code samples and 16 models (reported at https://www.helpnetsecurity.com/2025/04/14/package-hallucination-slopsquatting-malicious-code/).
- Grounding coding agents in current facts has proven pull: `@upstash/context7-mcp` had 404,726 npm downloads last week (https://api.npmjs.org/downloads/point/last-week/@upstash/context7-mcp) and the repo has 62,432 stars (https://github.com/upstash/context7). Context7 covers docs, not package facts.
- The earlier leader in this exact niche, `sammcj/mcp-package-version`, reached 122 stars and was archived on 2026-03-29, its author folding it into a general devtools server (https://github.com/sammcj/mcp-package-version). Demand existed; the focused incumbent left.
- Registry search for "package" returns 31 entries, mostly thin one-registry wrappers (https://registry.modelcontextprotocol.io/v0/servers?search=package).

Incumbents and weaknesses:
- `MShekow/package-version-check-mcp`: 8 stars, pushed 2026-09-26, 1 open issue (https://github.com/MShekow/package-version-check-mcp); PyPI 168 downloads last week (https://pypistats.org/api/packages/package-version-check-mcp/recent). Versions only; no existence risk scoring, vulnerabilities or licences.
- `loonghao/pypi-query-mcp-server`: 19 stars, 23 open issues, PyPI 34 last week (https://github.com/loonghao/pypi-query-mcp-server, https://pypistats.org/api/packages/pypi-query-mcp-server/recent). One ecosystem.
- `StacklokLabs/osv-mcp`: 42 stars, 21 open issues (https://github.com/StacklokLabs/osv-mcp). Vulnerabilities only.
- Google ships an experimental MCP mode in osv-scanner (`osv-scanner experimental-mcp`, https://google.github.io/osv-scanner/experimental/). It scans for vulnerabilities; it does not answer version, deprecation or existence questions. This is the one official neighbour, and it is marked experimental.

Data: registries (npm, PyPI, crates.io, Maven Central, Go proxy, NuGet, RubyGems) are free and keyless. deps.dev v3 answered keyless (HTTP 200 on https://api.deps.dev/v3/systems/npm/packages/react) and its generated data is CC-BY 4.0 with caching explicitly allowed (https://docs.deps.dev/api/v3/). OSV answered keyless (HTTP 200 on POST https://api.osv.dev/v1/query). Rate limits for deps.dev are not published (not measured).

How we win:
- One call, whole manifest, seven or more ecosystems, compact per-line verdicts instead of raw registry JSON.
- A published golden set: a frozen snapshot of real, deprecated, yanked, typo-squat and non-existent names with expected verdicts, re-checked in CI. No incumbent publishes accuracy numbers (not measured beyond reading their READMEs).
- A "does this name look like a slopsquat" check (existence plus age plus download floor plus name distance to a popular package).
- Hosted endpoint plus local npx/uvx; no key.

### 3.2 Scholarly reference verifier and repairer (score 16, effort M)

What it is: give it a reference list, BibTeX file or manuscript text; it checks every citation against Crossref, OpenAlex, arXiv, PubMed and DataCite, flags fabricated or mismatched entries, flags retractions, and returns corrected BibTeX with DOIs.

Demand evidence:
- Hallucinated citations are a live, measured harm: Damien Charlotin's court database lists 2,079 decisions involving AI-hallucinated material as of late September 2026 (count reported via search summary of https://www.damiencharlotin.com/hallucinations/; the same tracker is archived at https://zenodo.org/records/21845901).
- Research-workflow MCP servers have real users: `arxiv-mcp-server` 15,629 PyPI downloads last week and 3,175 stars (https://pypistats.org/api/packages/arxiv-mcp-server/recent, https://github.com/blazickjp/arxiv-mcp-server); `zotero-mcp-server` 5,798 PyPI downloads last week and 5,166 stars (https://pypistats.org/api/packages/zotero-mcp-server/recent, https://github.com/54yyyu/zotero-mcp).
- A 2026 paper describes an MCP server for exactly this task (citecheck, https://arxiv.org/abs/2603.17339), showing academic interest.

Incumbents and weaknesses: all tiny. `tfscharff/doi-mcp` 15 stars (https://github.com/tfscharff/doi-mcp); `benchoi93/refcheck` 3 stars, last push 2026-04-08 (https://github.com/benchoi93/refcheck); `JonasBaath/mcp-refchecker` 0 stars (https://github.com/JonasBaath/mcp-refchecker). Registry search "citation" returns 11 small entries (https://registry.modelcontextprotocol.io/v0/servers?search=citation). OpenAlex now runs an official MCP (https://github.com/ourresearch/openalex-mcp-server) but it is a search tool, not a verifier.

Data: Crossref keyless (HTTP 200 on https://api.crossref.org/works/10.1038/nature12373) with rate limits tightened from 2025-12-01 and again 2026-07-21 (https://www.crossref.org/blog/announcing-changes-to-rest-api-rate-limits/). Retraction Watch data is free inside the Crossref API, updated every working day (https://www.crossref.org/blog/retraction-watch-retractions-now-in-the-crossref-api/). OpenAlex answered keyless on a test call (HTTP 200) but its official MCP runs on a user key where free keys get USD 1 per day (https://github.com/ourresearch/openalex-mcp-server). arXiv and PubMed E-utilities are free.

How we win: a published benchmark of seeded fake and corrupted references with precision and recall; retraction flags on every check (none of the three verifiers above mention retractions in their descriptions); BibTeX in, BibTeX out; multi-source fallback so one source's rate limit does not fail the check; hosted plus local. Legal case citations are out of scope because CourtListener's official server covers them (see rejections).

### 3.3 Medication label intelligence (score 15, effort M)

What it is: answer drug questions from the official FDA label text with section-level citations: indications, boxed warnings, contraindications, the drug interactions section, pregnancy, dosing, plus name normalisation (brand, generic, NDC to RxCUI), recalls and shortages. Framed as label lookup, not medical advice.

Demand evidence:
- NLM discontinued the RxNav drug-drug interaction API on or about 2024-01-02 (https://lhncbc.nlm.nih.gov/RxNav/APIs/InteractionAPIs.html; migration write-ups at https://blog.drugbank.com/nih-discontinues-their-drug-interaction-api/). A free replacement has not appeared; commercial services now sell it (https://www.rxlabelguard.com/blog/nlm-rxnav-drug-interaction-api-discontinued-migration-guide).
- openFDA servers see steady use: `@ythalorossy/openfda` 791 npm downloads last week, `@cyanheads/openfda-mcp-server` 295 (https://api.npmjs.org/downloads/point/last-week/@ythalorossy/openfda, .../@cyanheads/openfda-mcp-server). The second is near the noise floor described in section 1.
- Registry search "drug" returns 11 entries, including commercial label servers (https://registry.modelcontextprotocol.io/v0/servers?search=drug).

Incumbents and weaknesses: each covers one source. DailyMed servers have 0 to 3 stars (`RowanErasmus/dailymed-mcp-server` 3, https://github.com/RowanErasmus/dailymed-mcp-server). `genomoncology/biomcp` (643 stars, https://github.com/genomoncology/biomcp) covers drugs as one part of a broad biomedical server; label-section extraction depth was not measured.

Data: DailyMed, RxNav (RxNorm endpoints still live) and openFDA all answered keyless (HTTP 200 on https://dailymed.nlm.nih.gov/dailymed/services/v2/spls.json?drug_name=metformin, https://rxnav.nlm.nih.gov/REST/rxcui.json?name=metformin, https://api.fda.gov/drug/label.json?limit=1). US federal works, public domain.

How we win: parse SPL XML into typed sections once, cache locally, and answer with the exact label paragraph and set ID; golden set of known label facts (for example boxed warnings on named products) checked in CI; one tool that resolves any drug name form first. Risk: medical-liability framing needs care in docs and outputs.

### 3.4 Multilingual dictionary from Wiktionary (score 15, effort M to L)

What it is: definitions, part of speech, inflection tables, IPA, etymology, synonyms and translations across hundreds of languages, from the Wiktextract extraction of Wiktionary, served from our own index.

Demand evidence: weaker than the others, so Demand scores 2. `tatuylonen/wiktextract` has 1,276 stars and `reader-dict/monolingual` 974 (https://github.com/tatuylonen/wiktextract, https://github.com/reader-dict/monolingual), showing developer appetite for this data. Language learning and translation are common chat uses but MCP-specific pull was not measured.

Incumbents and weaknesses: essentially none. `pipeworx-io/mcp-wiktionary` 2 stars, a live-API wrapper (https://github.com/pipeworx-io/mcp-wiktionary); `Eyalm321/multilingual-dictionary-mcp` 5 stars (https://github.com/Eyalm321/multilingual-dictionary-mcp). Registry search "dictionary" returns 8 small entries (https://registry.modelcontextprotocol.io/v0/servers?search=dictionary).

Data: Kaikki.org publishes Wiktextract output, updated "usually at least once a week"; the English edition main file is 2.7 GB compressed, 23.5 GB uncompressed, covering hundreds of languages (https://kaikki.org/dictionary/rawdata.html). Wiktionary text is CC BY-SA (https://en.wiktionary.org/wiki/Wiktionary:Copyrights), so attribution and share-alike apply to outputs.

How we win: offline index means fast, no upstream rate limits, and structured inflection data that live-page wrappers cannot give; compact answers; goldens sampled from Wiktionary entries. Hosting a multi-GB index is the main cost.

### 3.5 Clinical code sets with rule checks (score 14, effort M)

What it is: look up, validate and cross-walk ICD-10-CM, ICD-10-PCS, HCPCS Level II, NDC and LOINC, and apply the official ICD-10-CM tabular rules (Excludes1/Excludes2, "code also", required 7th characters, billable versus header codes) so an agent cannot emit a non-existent or non-billable code.

Demand evidence: medical coding with LLMs is well studied and code hallucination is a named failure (for example https://www.medrxiv.org/content/10.1101/2024.10.15.24315526.full.pdf). `@cyanheads/medical-codes-mcp-server` shows 788 npm downloads last week, above the noise floor of its sibling packages (https://api.npmjs.org/downloads/point/last-week/@cyanheads/medical-codes-mcp-server). Commercial entries exist (io.accurecord/icd10-coding, https://glama.ai/mcp/connectors/io.accurecord/icd10-coding).

Incumbents and weaknesses: `cyanheads/medical-codes-mcp-server` (2 stars, https://github.com/cyanheads/medical-codes-mcp-server) is competent: an offline SQLite + FTS5 bundle of ICD-10-CM, ICD-10-PCS, HCPCS, RxNorm and RxClass with a validity check. It excludes LOINC and SNOMED for licence reasons. Whether it applies Excludes and 7th-character rules was not measured. Gap is therefore scored 3, not higher.

Data: NLM Clinical Table Search Service is free and keyless (HTTP 200 on https://clinicaltables.nlm.nih.gov/api/icd10cm/v3/search?terms=tuberc; about page https://clinicaltables.nlm.nih.gov/about.html). CMS and CDC code files are public domain. LOINC is free under its own licence terms; SNOMED CT and CPT are licence-restricted and should stay out.

How we win: rule-aware validation with a golden set built from the official tabular list; LOINC included under its terms; FY versioning so answers name the code-set year. Pairs naturally with 3.3 as a "clinical reference" family.

## 4. Short notes on ranks 6 to 15

6. Earth observation (STAC). Earth Search answered keyless (HTTP 200 on https://earth-search.aws.element84.com/v1/collections). Best incumbent `isaaccorley/planetary-computer-mcp` has 4 stars, last push 2026-04-16 (https://github.com/isaaccorley/planetary-computer-mcp). Curated geo MCP list `sparkgeo/geo-mcp-servers` has 110 stars (https://github.com/sparkgeo/geo-mcp-servers). Win by cloud-cover filtering, thumbnails and multi-catalogue search in one call. Demand is thin.
7. Internet standards reference. `higebu/rfc-mcp` 3 stars and `shuji-bonji/rfcxml-mcp` 4 stars (from `gh search repos "rfc mcp"`). IETF, IANA and Unicode data are free. Win with section-level retrieval, errata and obsoleted-by chains plus IANA registries in one server. Demand not measured beyond these.
8. Product recall checker. CPSC, NHTSA and openFDA recall endpoints answered keyless (HTTP 200 on https://www.saferproducts.gov/RestWebServices/Recall?format=json..., https://api.nhtsa.gov/recalls/recallsByVehicle?..., https://api.fda.gov/drug/label.json). 35+ registry entries, several commercial (https://registry.modelcontextprotocol.io/v0/servers?search=recall). `@cyanheads/cpsc-recalls-mcp-server` 535 npm last week. Win by one query across agencies and model/UPC matching; EU Safety Gate and Health Canada access not measured.
9. Federal regulations point in time. eCFR and Federal Register answered keyless (HTTP 200 on https://www.ecfr.gov/api/versioner/v1/titles.json, https://www.federalregister.gov/api/v1/documents.json?per_page=1). But GPO now runs an official GovInfo MCP in public preview (https://www.govinfo.gov/features/mcp-public-preview), and `1102tools-dev/federal-contracting-mcps` (24 stars, https://github.com/1102tools-dev/federal-contracting-mcps) and `cyanheads/federal-regulations-mcp-server` (328 npm last week) cover eCFR and Regulations.gov. Gap 2. Only worth it for "what changed in this CFR part between two dates" diffs.
10. Nutrition calculator. USDA FoodData Central is CC0 but needs a free data.gov key, 1,000 requests per hour per IP (https://fdc.nal.usda.gov/api-guide/). Incumbent `akutishevsky/nutrition-mcp` 63 stars, 11 open issues, is a meal tracker rather than a verified calculator (https://github.com/akutishevsky/nutrition-mcp). Win with unit-aware recipe parsing checked against USDA goldens.
11. OpenStreetMap. Clear demand: `osm-mcp-server` 1,515 PyPI downloads last week (https://pypistats.org/api/packages/osm-mcp-server/recent); `jagan-shanmugam/open-streetmap-mcp` 225 stars, last push 2025-07-12, 9 open issues (https://github.com/jagan-shanmugam/open-streetmap-mcp). Blocked by data: the public Nominatim policy sets "an absolute maximum of 1 request per second" and applies limits across all users of an app (https://operations.osmfoundation.org/policies/nominatim/). A good hosted server means self-hosting Nominatim/Photon, which breaks the tiny budget.
12. GTFS transit. Incumbents 0 to 2 stars (`jdamcd/gtfs-mcp` 2, from `gh search repos "gtfs mcp"`). Feed licences vary by agency (not measured); journey planning needs a routing engine. Effort L.
13. Dataset discovery. Hugging Face has an official MCP (298 stars, https://github.com/huggingface/hf-mcp-server); the rest is scattered. Low measured demand.
14. Grants and contracting. Served by the active, free 1102tools suite (above) and cyanheads (`@cyanheads/grantsgov-mcp-server` 103 npm last week). SAM.gov key limits not measured. Gap 2.
15. Patents. `riemannzeta/patent_mcp_server` 81 stars, pushed 2026-09-19, 0 open issues (https://github.com/riemannzeta/patent_mcp_server). 23 registry entries, several commercial (https://registry.modelcontextprotocol.io/v0/servers?search=patent). USPTO ODP and EPO OPS both need keys with quotas (quotas not measured).

## 5. Rejected niches

1. US case law and legal citation lookup. Free Law Project runs an official hosted CourtListener MCP at https://mcp.courtlistener.com/ launched in May 2026 (https://free.law/2026/05/12/courtlistener-is-now-available-inside-claude/), covering opinions, PACER dockets, citation analysis and judges. The source owner is the incumbent. Not winnable.
2. Web accessibility and Lighthouse audits. Google's Chrome DevTools MCP has 52,618 stars and 2,457,419 npm downloads last week (https://github.com/ChromeDevTools/chrome-devtools-mcp, https://api.npmjs.org/downloads/point/last-week/chrome-devtools-mcp) and includes a `lighthouse_audit` tool covering accessibility (https://developer.chrome.com/docs/devtools/agents). `mcp-accessibility-scanner` adds 2,263 npm downloads last week (https://api.npmjs.org/downloads/point/last-week/mcp-accessibility-scanner). Not winnable.
3. Public statistics (US Census, world development data). The Census Bureau publishes an official MCP (97 stars, https://github.com/uscensusbureau/us-census-bureau-data-api-mcp) and Google's Data Commons MCP is official and hosted on Google Cloud (https://developers.googleblog.com/access-public-data-insights-faster-data-commons-mcp-is-now-hosted-on-google-cloud/), now also carrying UN System data. Not winnable.
4. Standalone scholarly search and biomedical literature. OpenAlex runs an official MCP (https://github.com/ourresearch/openalex-mcp-server); arXiv is led by `blazickjp/arxiv-mcp-server` (3,175 stars, 15,629 PyPI last week); PubMed by `@cyanheads/pubmed-mcp-server` (4,898 npm last week, https://api.npmjs.org/downloads/point/last-week/@cyanheads/pubmed-mcp-server) and BioMCP (`biomcp-python` 4,429 PyPI last week, https://pypistats.org/api/packages/biomcp-python/recent). Search is taken; verification (rank 2) is the open angle.
5. Weather. `weather-mcp/weather-mcp` (npm `@dangahagan/weather-mcp`, 3,700 downloads last week, 17 tools, pushed 2026-09-25; https://github.com/weather-mcp/weather-mcp) is active, and the best free global source, Open-Meteo, is non-commercial only with 10,000 calls per day (https://open-meteo.com/en/pricing). Weak gap and restrictive data.
6. Vulnerability lookup on its own. Google's osv-scanner (11,090 stars) ships an experimental MCP mode (https://github.com/google/osv-scanner, https://google.github.io/osv-scanner/experimental/); `mukul975/cve-mcp-server` has 1,587 stars (https://github.com/mukul975/cve-mcp-server). Folded into rank 1 as one signal instead.
7. Wikidata and code documentation. Wikimedia Deutschland maintains an official Wikidata MCP (https://github.com/wmde/WikidataMCP); Context7 dominates library docs (404,726 npm last week). Not winnable.

## 6. Method and limits

- GitHub data from `gh search repos` and `gh api repos/<owner>/<repo>` on 2026-09-26; stars, push dates and open-issue counts are as of that call. The GitHub search API rate-limited part of the run; the affected queries were re-run.
- npm weekly downloads from https://api.npmjs.org/downloads/point/last-week/<pkg> (window 2026-09-18 to 2026-09-24). PyPI from https://pypistats.org/api/packages/<pkg>/recent (last_week field).
- Registry counts from https://registry.modelcontextprotocol.io/v0/servers?search=<term>&limit=100; counts are distinct names on the first page, and a "next" cursor means more exist.
- Keyless checks are single HTTP calls made on 2026-09-26; they show access, not sustained rate limits.
- Not measured: Glama, Smithery, mcp.so and PulseMCP install counts; Reddit and Hacker News thread volume; output quality of incumbents (no incumbent was run against a golden set). Those are the next checks before committing to rank 1 or 2.
