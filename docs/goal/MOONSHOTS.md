# Quantavane moonshots

Owner, 2026-10-21: once Quantavane is very big, run many projects like "talking to animals" across every branch,
and aim for the top of each field. Each project needs a way to check results before anything is claimed. These are
long-term candidates, not commitments with dates. They start only after the core lab has results and funding.

| Branch | Project | How a result is checked |
| --- | --- | --- |
| Mathematics | Settle famous open problems, starting with Erdős problems | Lean proof that compiles |
| Mathematics | Formalise major areas of maths so every theorem is machine-checked | Lean library builds |
| Physics | New exact solutions and better bounds in fundamental physics | Derivation checked symbolically and numerically |
| Physics | Room-temperature superconductor candidates | Simulation, then lab synthesis by partners |
| Algorithms | Faster core algorithms (matrix multiply, sorting, compression) | Correctness tests and benchmarks |
| Chips | AI-designed circuits and chip layouts | Circuit simulation and fabrication partners |
| Biotech | Designed proteins and enzymes, e.g. plastic-eating enzymes | Structure prediction, then wet-lab assays |
| Medicine | Drug candidates for neglected diseases | Docking and simulation, then partner lab trials |
| Medicine | Early disease detection from scans | Held-out clinical data, regulatory review |
| Neuroscience | Models of how brains encode language and memory | Prediction of recorded neural data |
| Animal communication | Decode whale, bird, elephant and primate communication | Playback experiments with field researchers |
| Ancient languages | Decipher undeciphered scripts such as Linear A and the Indus script | Readings that hold up on new inscriptions |
| Materials | Better battery and solar materials | Simulation, then synthesis and testing |
| Energy | Fusion plasma control and reactor design | Simulation, then partner experiments |
| Climate | Carbon capture materials and better climate models | Lab tests; forecasts scored against observations |
| Agriculture | Drought-resistant crops and better fertiliser chemistry | Greenhouse and field trials with partners |
| Space | Mission design and orbit optimisation | Physics simulation |
| Robotics | Controllers that learn new physical skills fast | Real-robot trials |
| Oceans | Map and understand ocean ecosystems from sound and sensor data | Predictions checked against new surveys |
| Engineering | Antennas, optics and structures nobody has designed | Simulation, then prototypes |

## Spin-out candidates (owner, 2026-10-21)

Quantavane powers sister startups built on its tracks. A track becomes its own company when it has a verified
result and a paying customer; until then it stays a lab track or a feature of an existing company.

| Area | Home | Note |
| --- | --- | --- |
| Post-quantum cryptography and cyber-defence | New startup candidate | Proofs cover implementations and reductions, not "unbreakable" claims; vulnerability finding stays defensive with responsible disclosure |
| Chip design (EDA) | New startup candidate, later | Logic is checkable in simulation; timing, power and fabrication need partners; incumbents are Synopsys and Cadence |
| Formal software verification | TraceAxiom | Product line inside TraceAxiom, not a separate company |
| Quantitative finance | CanliCapital and ALPHAC | Already exists; the checker must be untouched out-of-sample data, since backtests alone are where overfitting lives |
| Compiler and database optimisation | Quantavane algorithms track, deployed in Cirrun | Results upstreamed to open projects where possible |
