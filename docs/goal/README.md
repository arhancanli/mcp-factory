# CanliLabs goal

Owner: Arhan Canli. Expanded: 2026-10-13. The 2026-10-20 expansion (the lab renamed Quantavane, with its invention
lab) is kept in the owner's private records since 2026-10-22. Status: active.

Build CanliLabs into an AI research and engineering laboratory with thousands of
useful MCP servers and reproducible systems for data, machine learning, deep
learning, reinforcement learning, model evaluation, and model delivery.

The owner explicitly requested persistent goal work and preservation of the
earlier objectives. The recovered project is `arhancanli/mcp-factory`, branded
Canli Labs in `factory.config.json`. Its original objectives are in
[`docs/SPEC.md`](../SPEC.md), dated 2026-09-26. This goal extends that specification.
It does not replace its measurement, installation, maintenance, or adoption goals.

"Thousands" initially means a floor of **2,000 distinct released servers** with
evidence of useful coverage and quality. This is a planning interpretation of the
owner's request, not a claim about the current count. Duplicate renames and
generated skeletons do not count. The floor can increase without relaxing gates.
"Best" and "perfect" mean explicit acceptance criteria and measurements against
real alternatives. No absolute superiority claim is made without that evidence.

The active goal is also registered with the session goal system. These files are
the durable continuation record across sessions, worktrees, and compaction:

| Record | Purpose |
| --- | --- |
| [REQUIREMENTS.md](REQUIREMENTS.md) | Every owner objective and the evidence needed to close it |
| [PHASES.md](PHASES.md) | Dependency order, bounded milestones, and exit gates |
| [STATUS.md](STATUS.md) | Verified current state and next action |
| [LOG.md](LOG.md) | Decisions, material changes, validation, and handoffs |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Factory, laboratory, data, evaluation, and operations |
| [COVERAGE.md](COVERAGE.md) | Training and research disciplines that must be supported |
| [SOURCES.md](SOURCES.md) | Recovered intent and current technical references |

Work only on CanliLabs here. Existing finance, trading, and quant projects retain
their separate CanliCapital/ALPHAC goals. Existing CanliLabs scout records exclude
finance, quant, and trading.

Resume procedure: read the five continuity records; inspect the working tree and
open PR; verify the last milestone's evidence; select the first unmet exit gate;
implement a bounded change; run its checks; record results and the next action.
Do not keep repeating passing checks without a change or an unresolved concern.
