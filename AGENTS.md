# CanliLabs continuity

This repository is CanliLabs' MCP factory and AI laboratory. Before each new phase,
and immediately after context compaction, read `docs/goal/README.md`,
`REQUIREMENTS.md`, `STATUS.md`, `PHASES.md`, and `LOG.md`. Verify the actual files,
Git state, release evidence, and pull requests before relying on a dated status.
Update the goal records at material transitions. Preserve every requirement from
the original `docs/SPEC.md` and the owner's 2026-10-13 expansion.

Count separately: proposed niches, implemented servers, tested servers, benchmark
winners, published versions, and maintained releases. A package name, generated
wrapper, catalog entry, or passing protocol test does not prove release or quality.
The overall goal remains active until all acceptance criteria have evidence.

Keep model weights, private datasets, credentials, environments, and working run
databases out of Git. Record small, non-sensitive validation receipts instead.
Run the checks appropriate to each changed workstream. Use the existing owner
identity and signing configuration for commits. Prepare pull requests; merging
and owner-authored launch posts follow the existing project policy.
