# Security

Report a vulnerability privately through GitHub's "Report a vulnerability" button on this
repository's Security tab. You will get a reply within two days.

What every server guarantees, and the gate tests: HTTPS only, to a declared host allowlist that is
re-checked on every redirect; response size caps and deadlines; no retries of anything but reads;
bounded tool inputs; error messages that never contain upstream bodies, keys or query strings;
exact-pinned dependencies with a shrinkwrap for every install path.
